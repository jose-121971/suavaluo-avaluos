# Suavalúo · Validación de avalúos (Resolución IGAC 941 de 2026)

Skill para **validar informes de avalúo** en Colombia contra la **Resolución IGAC 941 de 2026**: aplicabilidad, etapas (art. 13), contenido (art. 14), método, estudio de mercado (art. 21), uso del suelo y vigencia. Entrega un informe de validación con los numerales del informe, agrupado en **lo bueno / por corregir / por ajustar**, y una conclusión.

## Qué es
- Es una **skill** (instrucciones para un asistente de IA), no un programa ni un conector.
- En **Claude** se usa como skill; en otra IA, el archivo SKILL.md se puede pegar como instrucciones.

## Cómo usarla
- **En claude.ai:** Ajustes, Skills, cree una skill nueva y use el contenido de SKILL.md.
- **En otra IA (ChatGPT, Gemini):** abra SKILL.md y péguelo como instrucciones del asistente.

## Aviso
Es apoyo metodológico. El avaluador RAA revisa, decide el valor y firma; responde por el informe (Ley 1673 de 2013). Verifique siempre el texto vigente de la Resolución IGAC 941 de 2026 ante el IGAC / Diario Oficial.
